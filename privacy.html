box-gmail privacy policy

Last updated: 24 November 2026.

  • box-gmail is used only by its owner, for the owner's own Gmail accounts.
  • Mail data is read on the owner's own private server, only to help the owner sort, read and answer mail.
  • Mail data is not sold, not shared with third parties, and not used for advertising.
  • Access tokens are stored only on the owner's server and can be revoked at any time at myaccount.google.com/permissions.
  • box-gmail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
